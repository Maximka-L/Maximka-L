### 👨‍💻 Обо мне

Привет! Я **Android-разработчик** с сильной инженерной базой (**Школа 21**, алгоритмы и C/C++) и практическим опытом разработки современных приложений на стеке **Kotlin / Jetpack Compose / Coroutines** (выпускник **Яндекс Практикума**).

- 📱 Специализируюсь на нативной Android-разработке (Single Activity, Clean Architecture, MVVM).
- 🎨 Создаю адаптивный и отзывчивый UI на **Jetpack Compose** (Material 3) и классическом **View Binding / XML**.
- ⚙️ Фокусируюсь на реактивном подходе (**Coroutines & Flow**), стабильности сетевого слоя и локальном кэшировании (**Room**).
- 🤝 Имею опыт командной разработки по **Agile/Scrum** (Git Flow, GitLab MRs, Code Review).
- 🛠️ Бэкграунд старшего инженера техподдержки в **ПАО «МегаФон»** развил системный навык траблшутинга, внимание к SLA/стабильности сервисов и умение быстро находить первопричины сбоев.
